Production Engine

Unified In-Memory Client

Process raw PDFs, CSVs, JSON, and live PostgreSQL tables into 3072D embeddings with real-time 5-stage telemetry trace in ~2 milliseconds.

app.py 
import nexus

# 1. Thread-safe in-memory client (zero disk I/O)
client = nexus.NexusClient(in_memory_only=True)

# 2. Pipeline document with 5-stage telemetry
doc = client.process_document(
    document_id="doc-01",
    name="salaries.csv",
    text="Emp,Salary,Card\nAditya,120k,4532-8921-1123-9988",
    file_type="csv",
    enable_guardrails=True
)

print(doc.summary)
# Projected 3072D vector (L2 norm = 1.0)
Real-Time Execution Trace

5-Stage Telemetry Breakdown

1. Document Ingestion & UTF-8 Normalization 0.02 ms

Normalizes UTF-8 content, standardizes CRLF endings, and computes SHA-256 / MD5 content hashes.

2. Format-Aware Structural Chunking 0.04 ms

Generates tabular narratives with [Row ID: x], preserving column headers and structure.

3. Metadata & Entity Classification 0.03 ms

Classifies domain taxonomy, extracts entities, and creates immutable audit metadata.

4. Safety Guardrails & PII Sanitization 0.25 ms

Redacts Luhn credit cards, SSNs, and emails when enabled (or bypasses with enable_guardrails=False).

5. 3072D Vector Projection (IEEE 754) 1.76 ms

Projects unit-normalized 3072-dimensional embeddings compatible with PostgreSQL vector(3072).

Architecture

Seven Loosely Coupled Layers

Each layer is an independently installable package adhering to zero inter-layer import constraints.

Layer 1

Data Connectivity

Multi-source ingestion for REST APIs, batch directory drops, CSVs, and real-time database CDC event streams.

  • Same-origin redirect security
  • Debezium CDC streaming
  • Batch directory watchers
Layer 2

Processing & Enrichment

Context-preserving structural tokenization, row narrative generation, and domain classification.

  • CSV row narratives [Row ID: x]
  • JSON object block extraction
  • Unicode normalization
Layer 3

Retrieval Intelligence

Unit-normalized 3072D embeddings, BM25 lexical indexing, knowledge graph traversals, and hybrid RRF fusion.

  • 3072D vector projections
  • IEEE 754 exact precision ($L_2=1.0$)
  • Reciprocal Rank Fusion
Layer 4

Orchestration & Guardrails

Strict policy enforcement, regex PII scrubbers with Luhn checksum validation, and grounded RAG verification.

  • Luhn credit card redaction
  • Prompt injection filters
  • Grounded citation verification
Layer 5

Experience & Channels

Lightweight FastAPI gateway, Python SDK client, and interactive AI assistant interfaces.

  • FastAPI REST endpoints
  • In-memory gateway
  • Interactive assistant channels
Layer 6

Security & Governance

Multi-tenant isolation, dynamic tenant-bound HKDF key derivation, RBAC primitives, and tamper-proof audit trails.

  • Dynamic HKDF cryptographic salting
  • Role-based access control
  • Tamper-evident audit logging
Layer 7

Observability & Monitoring

Real-time telemetry, structured event logging, distributed span tracing, and Prometheus metrics exporters.

  • Prometheus metrics exporter
  • Distributed span traces
  • Rule-based alerting engine
